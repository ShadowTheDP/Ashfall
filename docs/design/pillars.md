# 五根柱子與範圍

這份文件固定「這個遊戲是什麼」與「先做什麼」。任何新系統都應先對照這裡，
避免在 Milestone 0 就滑向 meta 進度或內容量產。

## 五根柱子

| # | 柱子 | 一句話 | 目前狀態 |
|---|---|---|---|
| 1 | 戰鬥手感 | 打擊重量、翻滾無敵幀、取消窗口、輸入緩衝 | **Milestone 1：可玩 + 三種函數武器** |
| 2 | 房間拼接 | 手工房間 + socket 規則拼接，不是純程序生成 | 尚未開始 |
| 3 | Build 系統 | 2 武器 + 2 技能 + 3 突變 + 三色屬性 | 有 7 種通用 boon（波間三選一），三色屬性尚未接 |
| 4 | 死亡循環 | 死亡失去 run，只留永久解鎖 | 尚未開始（只有 run 內細胞與 run 內 boon） |
| 5 | Metroidvania 閘門 | 符文/能力解鎖新路線 | 尚未開始 |

核心判斷：**玩家 90% 的體驗來自柱子 1**，所以先做手感，再做內容。
柱子 2/3/4/5 都好寫，但寫早了只會讓手感問題被內容掩蓋。

## 柱子 1：戰鬥手感（目前焦點）

已實作並可調的機制：

- 三段正弦劍，每段有 windup / active / recovery / cancel 點
- 攻擊輸入緩衝與連段排隊
- 第三段釋放正弦行進波（`FunctionWave`），可穿透多個敵人
- 拋物線飛刀：解 `v0` 命中目標、顯示軌跡預覽、重力下墜
- Aegis 護盾：徑向場格擋 + 近距離反擊波
- **Perfect Dodge**：翻滾穿過攻擊 → 2.5 秒 +25% 傷害並返還一把飛刀
- 翻滾：位移曲線、無敵幀、冷卻、攻擊取消
- 受擊硬直、擊退、受擊後無敵
- Hitstop（命中凍結）、鏡頭 trauma shake、命中火花、傷害數字
- 暴擊窗口：敵人處於預警/攻擊/收招時，或在背後攻擊
- Coyote time、jump buffer、可變跳躍高度、落地擠壓
- 音效回饋（全部程式合成）與 32 秒無縫音樂

**下一步不是加更多招式，而是用真人試玩調參。**
調參入口與目前數值見 [`combat-feel.md`](combat-feel.md)。

## 柱子 2：房間拼接（下一個系統）

Dead Cells 的公開做法不是「生成房間」，而是：

1. 設計師手工做房間，每個房間有入口/出口 socket
2. 生成器按 biome 規則挑房間、按 socket 拼接
3. 用關鍵路徑規則保證連通與節奏（戰鬥/獎勵/商店/精英比例）
4. 出口用符文閘門鎖住，形成 metroidvania 結構

**建議的第一刀（不寫生成器）：**

- 定義 `RoomTemplate { entrances[], exits[], tags[], difficulty }`
- 手工串接 3 個房間（A → B → C），用一個 `RoomChain` 資料檔
- 相機在換房時做一次 limit 過渡與短暫 fade
- 驗證：玩家能從 A 走到 C，死亡後重來仍在 A

**先不要做**：隨機拼接、seed、biome 權重、小地圖。等 3 個手工房間的
「換房手感」對了，再談生成。

## 柱子 3：Build 系統（資料先行）

目標形狀：

| 元素 | 設計 |
|---|---|
| 三色屬性 | 紅（近戰/暴擊）、紫（遠程/陷阱）、綠（生存/召喚） |
| 卷軸 | 每次升級選一色，提升該色數值 |
| 武器 | 2 格；基礎傷、縮放色、攻速、詞條 |
| 技能 | 2 格；冷卻制 |
| 突變 | 3 格；改變玩法規則 |
| 詞條 | 隨機附加效果，稀有度控制數量 |

公式：`最終傷害 = 基礎傷 × (1 + 對應色 × 0.12) × 詞條乘數`

**現況**：`data/weapons.json` 與 `Damage` 已預留 `attribute` / 屬性縮放，
但屬性固定為 0。目前用 7 種通用 boon 代替三色卷軸（`data/rewards.json`），
先驗證「波間三選一」的節奏；等武器夠多再換成三色屬性。

## 柱子 4：死亡循環

```text
Run 開始 → 探索 → 戰鬥 → 拿細胞 → 死亡
   ↓
細胞 → 永久解鎖（新武器進池、新突變、新符文、+藥水）
   ↓
下一輪更強 → Boss Cell 0→5 解鎖更高難度
```

設計陷阱：永久解鎖要給「橫向多樣性」，不是純數值變強。
**Milestone 0 只做 run 內細胞**，不寫存檔。

## 柱子 5：Metroidvania 閘門

四個符文就夠撐起骨架：藤蔓（垂直）、蜘蛛（貼牆）、衝撞（破地板）、
傳送（捷徑）。等柱子 2 有 3 個手工房間後再接入。

## 藝術方針

視覺的唯一來源是 [`math-art.md`](math-art.md)：多邊形、星形、螺線、
Lissajous、玫瑰線、phyllotaxis、諧波、拋物線。
**不引入貼圖、不用 Sprite2D**，風格來自約束而不是更多元素。

## 不做清單（現階段）

- 不做多人、不做線上服務、不做排行榜
- 不做 Steam 整合、成就、雲端存檔
- 不做程序化美術、不做 3D
- 不引入第三方遊戲資產或逆向資料
