2026-10-23 11:40
- Summary: Milestone 2 - full pixel-art conversion plus action-game animation
  grammar. Logical resolution is now 640x360 with integer x2 upscaling, nearest
  filtering, camera zoom 1.0 with rounded position and no rotation. Every
  drawing call goes through new `MathArt.px_*` rasterisers (px_rect,
  px_circle, px_ring, px_arc, px_line, px_poly); all anti-aliased helpers were
  deleted. Characters are now pure geometric sigils (player = diamond + square
  core + line blade; enemies = triangle/square/hexagon/pentagon/circle) with
  particle trails doing the motion work. Combat animation now follows
  anticipation -> smear -> impact -> follow-through -> secondary motion.
- Subagent audits (three parallel `pi -p` scouts) produced
  `output/agent-reports/{scout-animation,scout-animation-spec,scout-pixel-qa}.md`
  and drove the fix list below.
